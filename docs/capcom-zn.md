# Capcom ZN daughterboard adapter

`libpcsxcore/arcade/capcom_zn.c` implements the Capcom daughterboard maps from MAME `src/mame/sony/zn.cpp`, pinned at `deb2f54fe7300e7a192690318beb860159bfd52a`. It is a standalone companion to the generic ZN board adapter: unrecognized main-bus addresses return `CAPCOM_ZN_UNMAPPED` for the caller's common ZN I/O and BIOS handlers.

The main bus exposes the first 4 MiB of the borrowed `bankedroms` region at `0x1f000000`, then a 4 MiB window at `0x1f400000`. Writes to `0x1fb00000` select the window entry from the low nibble. `0x1fb80000..0x1fbfffff` reads the 512 KiB country ROM. KICK1 and KICK2 are 32-bit active-low callback values at `0x1fb40010..13` and `0x1fb40020..23`; byte and halfword reads select little-endian lanes from those words. A write at `0x1fb60000` updates the sound latch and asserts the Z80 NMI input until the Z80 reads I/O port `0x00`.

The Z80 runs at nominal 8 MHz T-states. Its fixed ROM is `0x0000..0x7fff`, its `0x8000..0xbfff` window selects one of sixteen `0x4000` pages starting at audio-ROM offset `0x8000`, and `0xf000..0xffff` is 4 KiB RAM. Writes at `0xd000..0xd002` and reads at `0xd007` use the optional borrowed QSound HLE device, or the existing external QSound callbacks when no device is attached; writes at `0xd003` select the audio ROM page from the low nibble. The 250 Hz HOLD IRQ first expires 32,000 T-states after reset, then every 32,000 T-states, and clears on Z80 interrupt acknowledge. This phase follows MAME's `set_periodic_int(..., attotime::from_hz(250))` and `device_execute_interface::interface_post_reset`, which adjusts the timer with the full period as its initial delay.

ROM arrays are borrowed and never padded or rewritten by the adapter. For a mapped access, a source pointer that does not contain the complete requested lane returns `CAPCOM_ZN_FAULT` and records a bounds fault. This matters because the pinned driver declares a `0x2400000` byte main region while configuring sixteen 4 MiB window entries, and a `0x40000` byte audio region while configuring sixteen 16 KiB pages; this adapter preserves the selectors and rejects accesses beyond the supplied region. KICK callbacks remain required. QSound accesses fail closed when neither a borrowed device nor working external callbacks exist; no synthetic input value, QSound-ready bit, or audio response is invented.

Set `capcom_zn_config_t.qsound_hle` to a caller-owned `QSoundHLE` created using authentic caller-supplied firmware/coefficient words and sample ROM. It takes precedence over the external QSound callbacks. Creation rejects a borrowed device whose clock differs from 60 MHz, since the Capcom clock conversion assumes that source clock. The caller must keep the device alive and must not independently advance, reset or change its clock while the board is attached. Board destruction frees its Z80 and board allocation, and leaves the borrowed device intact. The fallback callback signatures and raw `0xd000..0xd002` write addresses are unchanged. See [qsound-hle-port.md](qsound-hle-port.md) for coefficients, command-register behavior and device limitations.

The borrowed device is synchronized before each executed Z80 QSound read/write and again at the exact end of each nominal sound budget. Inside a Z80 callback, `Z80Status.cycles` includes elapsed bus cycles from the current execution call; the callback occurs before charging its current bus cycle. `cycle_debt` is updated after execution returns and is not a callback timestamp. At run return, actual Z80 cycles can exceed nominal time through bus-cycle overshoot; that excess must not advance QSound. Direct diagnostic bus helpers use the committed nominal board time. No Z80 API extension is needed.

The 60 MHz QSound crystal divided by the 8 MHz Z80 clock gives 15/2 crystal clocks per Z80 T-state. QSound's DSP machine clock divides crystal clocks by two, so the implementation accumulates 15/4 machine cycles with a local remainder from zero to three. After nominal time `N`, the board advances exactly `floor(15*N/4)` QSound cycles and retains `(15*N)%4`. A one-T-state budget can execute two Z80 T-states with debt -1, but advances only three QSound machine cycles. Status exposes nominal and actual CPU time/debt, synchronized QSound time, its machine cycles and conversion remainder.

Board reset resets the borrowed HLE device, clears conversion/IRQ phase and nominal counters, and records a fresh origin for the Z80's retained cumulative clock. The HLE selective reset retains its source-defined stream grid and cumulative debug counters while clearing ready/output and restarting boot. This stream timing is distinct from the board's reset conversion remainder. Sound latch data and RAM retain the existing source behavior.

The original synthetic test program executes on the ported Z80. It changes the sound bank, reads the selected ROM byte, sends three QSound register writes, reads external status, acknowledges a main-CPU latch through an NMI, and services the periodic IRQ. Reset deasserts the NMI/IRQ lines and clears the latch's pending flag while retaining its byte and sound RAM, matching the MAME generic latch reset and RAM map. Additional checks cover main ROM aliases/lanes, bank pointer selection, KICK lanes, country ROM, callback failures, and out-of-range images.

The joint test executes another Z80 ROM against the actual borrowed HLE component. It polls `0xd007`, sends nine real commands through `0xd000..2`, and produces nonzero stereo PCM using explicitly marked synthetic coefficient/sample fixtures. A main latch NMI consumes port 0 and sends a tenth volume command, changing the audio sign. Whole, single-T-state and 17-T-state budgets give identical commands, frame counts and PCM samples. Every PCM callback checks that device time stays within the nominal scheduler endpoint. Tests also cover overshoot/debt, reset origins/fraction, diagnostic helpers, borrowed ownership and rejection of a 120 MHz device. These fixtures are not authentic game/DL-1425 media and do not establish production audio or Capcom ZN boot.

Run the standalone tests with:

```sh
make -f tests/Makefile.capcom-zn test
make -f tests/Makefile.capcom-zn test BUILD=build/capcom-zn-sanitizers \
  CFLAGS='-std=c99 -O0 -g -Wall -Wextra -Werror -fsanitize=address,undefined -fno-omit-frame-pointer' \
  CXXFLAGS='-std=c++17 -O0 -g -Wall -Wextra -Werror -fsanitize=address,undefined -fno-omit-frame-pointer'
```

Normal and ASan/UBSan tests pass, and the public header and board implementation compile as C99. The adapter and test carry the upstream BSD-3-Clause notice from MAME `zn.cpp`. The bundled Z80 and QSound HLE retain their separate upstream notices in `libpcsxcore/arcade/z80_LICENSE.txt` and `qsound_hle_LICENSE.txt`. This module supplies board mapping, CPU/latch/timer behavior and an optional composed audio path. Game-specific KICK input callbacks, authentic sound media and the common PSX/ZN system integration remain caller responsibilities.
