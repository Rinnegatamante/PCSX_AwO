# Konami K056800 MIRAC sound interface

`libpcsxcore/arcade/k056800.c/.h` adapts the complete implemented behavior of
MAME `src/devices/sound/k056800.cpp/.h` at revision
`deb2f54fe7300e7a192690318beb860159bfd52a`, copyright Ville Linde. Full BSD-3-Clause
terms are in `k056800_LICENSE.txt`. Konami GQ maps this interface between the
PSX host and its 68000 sound CPU; the source config supplies 18.432 MHz, but
the implemented device does not use that clock or schedule a timer.

The caller owns device storage and the optional IRQ callback. Four registers
carry host commands to sound; two registers carry sound replies to host.
Offsets mirror with `offset & 7`. Host register 7 asserts the callback and
sets pending only when interrupts are enabled. Sound register 4 bit 0 enables
interrupts; disabling clears pending and drives the callback low. Enabling an
already pending interrupt calls the callback high again. Repeated source
callbacks are retained even when the line value has not changed.

Reset clears all six data registers, pending and enable. It does **not** call
the interrupt handler, matching the pinned source; the diagnostic line value
therefore retains the last callback state until a later write. Volume/mute
controls, volume-busy reads and unknown sound registers retain the source's
no-op/zero behavior. This component does not implement the separate K054539,
TMS57002 or 68000, and does not establish GQ game boot or audio playback.

Read-only inspection is allowed during the IRQ callback. Nested writes/reset
return -1 and cannot mutate the active transaction; callbacks must not
reinitialize the caller-owned storage. Normal and ASAN/UBSAN validation:

```sh
make -f tests/Makefile.k056800 test sanitize
```

The tests verify cross-CPU registers and mirrors, ignored controls, disabled
commands, repeated callback assertions, acknowledgment, selective reset and
callback reentry rejection against the source's explicit register behavior.
