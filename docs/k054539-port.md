# Standalone Konami K054539 PCM engine

`libpcsxcore/arcade/k054539.c` ports the sound stream and register behavior of
MAME `src/devices/sound/k054539.cpp/.h` at
`deb2f54fe7300e7a192690318beb860159bfd52a`. Source copyright is Olivier
Galibert; its complete BSD-3-Clause notice is retained in
`libpcsxcore/arcade/k054539_LICENSE.txt`.

The C99 engine models eight voices, signed 8-bit PCM, little-endian signed
16-bit PCM, 4-bit delta PCM, pitch fractions, loop/end markers, reverse
playback, channel volume/pan/gain, key-on position latches, the position read
back registers, the 0x22d ROM/reverb port, 32 KiB of reverb RAM, global control,
and the chip timer. Reverb uses 16K signed words in the source's 32 KiB byte
array and the source's existing ring/delay calculation.

Create independent instances for the two GQ chips. Supply a sample callback
for each instance; the core never substitutes generated data. It passes a
24-bit byte address through to that callback. The Konami GQ address map in
pinned `src/mame/konami/konamigq.cpp` maps `0x000000..0x07ffff` to the chip's
sample ROM and `0x080000..0x3fffff` to shared PCM RAM. The caller provides the
actual board memory and source address-space value for unmapped addresses.
The caller owns that sample space and must also call the barrier before
changing any ROM-bank or shared PCM-RAM mapping that the callback observes.

Advance each chip by emulated chip-clock cycles before register writes,
`set_flags`, or `set_gain`. The
engine emits one raw signed 32-bit output pair every 384 chip clocks; at
18.432 MHz this is 48 kHz. The output matches the integer argument passed to
MAME `sound_stream::put_int` before its float normalization. It is deliberately
unclipped, so multi-voice/high-gain sums can exceed signed 16-bit range; the
host mixer or WAV writer owns final scaling and clipping. MAME synchronizes
the stream before writes, but its K054539 `read` handler does not force a
stream update, so callers should preserve that distinction. Synchronize before
flags/gain changes and ROM bank changes as upstream does. Ordinary GQ shared
PCM RAM writes have no source stream barrier. This standalone scheduler emits
samples as time advances; matching MAME's deferred stream batching across
those RAM writes needs a board/mixer timing model, and is not established by
these device tests.

The timer frequency follows MAME's float32 expression
`(38 + data) * (clock / 384 / 14400)`, converted with `from_hz()` and divided
by two. MAME stores its deadline as integer attotime; this port represents it
as a double chip-cycle deadline and services the first integer cycle at or
after it. The caller should keep rational remainders when converting host/core
time into chip cycles. To keep those double deadlines exact, this port rejects
timer configuration or advancement at/after cycle `2^53 - 1`; callers must
reset or recreate the chip before that horizon. Timer-less playback can advance
through the full unsigned 64-bit cycle range.
`REVERSE_STEREO` is declared upstream but is
not consulted by the current chip implementation; output routing belongs to
the board/mixer. Register `0x13f` reports pan gains for an external analog
source, but this engine does not synthesize that analog signal.

Callbacks run synchronously. They may inspect const registers and diagnostics,
but any access to port `0x22d` (including a side-effects-disabled read), reset,
write, flags/gain change, advance, or destroy attempt from a callback is
rejected; `k054539_callback_fault()` stays set for diagnostics. The owner can
perform the requested operation after the callback returns. Non-finite gain
values are rejected; finite negative gains are ignored as in MAME. High-gain reverb accumulation narrows through an explicit
16-bit wrap, matching the chip word behavior without relying on an out-of-range
floating-point-to-short conversion.

The model accepts clocks divisible by 384 so its sample divider remains exact;
the Konami GQ 18.432 MHz clock is supported. Validate decoding, mixing,
register-port behavior, timer edges, reset, and chunked cycle advancement with:

```sh
make -f tests/Makefile.k054539 test sanitize
```
